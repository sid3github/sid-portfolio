# Siddharth Padwal — Portfolio

Personal portfolio for Siddharth Padwal, Senior Frontend & Agentic AI Engineer.
Design direction inspired by [tajmirul.site](https://www.tajmirul.site/): dark
stage, acid-lime accent, oversized condensed display type, smooth scroll.

## Stack

- Next.js 16 (App Router, static output) + React 19 + TypeScript
- Tailwind CSS 4
- Lenis smooth scroll, IntersectionObserver reveals (reduced-motion safe)
- Fonts: Anton (display) · Instrument Sans (body) · JetBrains Mono (labels)

## Develop

```bash
npm install
npm run dev
```

All page content lives in [lib/data.ts](lib/data.ts) — edit copy, projects,
experience, and skills there. The CV PDF and portrait live in `public/`.

## Build

```bash
npm run build
```
